> **Course Project** | VIA University College — Game Development (GMD1)

This repository hosts my codebase, milestones, and documentation for **Spearhead: Nereus Protocol**, an arcade-style sci-fi shooter set on an oceanic world. This project serves as the outcome of my first course in Game Development.

<br>
